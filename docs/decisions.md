# Решения проекта

Актуализировано: 17 октября 2026 года. Это итог обсуждения, а не журнал каждого сообщения. Согласованные решения имеют приоритет над более ранними предложениями в чате; новые указания пользователя требуют обновления документации.

## Принято

| Решение | Причина / граница |
| --- | --- |
| Личное приложение на Home Lab | Один пользователь, основное устройство — телефон |
| Короткие сообщения и письма | Мессенджеры, работа, университет, административная переписка |
| MVP только Strict | Объективные исправления с минимальными изменениями |
| Ответ только исправленным текстом | Не нужны объяснения; экономия выходных токенов |
| Русский приоритетен | Качество проверяется прежде всего на русском |
| React + Vite, без Next.js | Достаточно клиентского интерфейса и отдельного API |
| shadcn/ui + Tailwind CSS | Типичные читаемые компоненты |
| Оба UI-прототипа утверждены 17 октября 2026 года | Коррекция и история: тёмная тема, яркий зелёный акцент, Roboto, английский UI; решения и передача в реализацию в `prototypes/README.md` |
| Fastify + Node.js | Небольшой API, плагинная организация |
| TypeScript на фронте и сервере, Zod-контракты | Общие типы и проверка внешних данных |
| SQLite | Достаточно для личной истории |
| npm workspaces | Простой monorepo; отказ от pnpm, Lerna и Turborepo |
| OpenRouter и смена модели | Модель выбирается после сравнения |
| Reasoning полностью выключен для всех моделей | Заменяет прежнее предложение low thinking; поддержку отключения проверить при настройке модели |
| Локальный diff и копирование одной кнопкой | Наглядность и быстрый мобильный сценарий |
| Автоматическая история | Основа будущего просмотра прошлых ошибок |
| VPN для OpenRouter | На компьютере системный VPN, на сервере явный HTTP-прокси из ENV |
| Без прямого fallback при ошибке прокси | Критическое сетевое ограничение |
| Авторизация и внешний доступ отложены | Пользователь просит не проектировать их сейчас |
| Краткий AGENTS.md и тематические docs | Контекст доступен новому агенту без всей переписки |

## Заменённые предложения

- Все три режима в первой версии заменены на Strict-only MVP.
- Minimal как режим по умолчанию неактуален; выбора режима в MVP нет.
- pnpm workspaces заменён на npm workspaces. Lerna и Turborepo также исключены.
- Обязательный strict: true был предложен преждевременно. Утверждено использование TypeScript, а не эта настройка.
- Обязательный прокси Home Lab для разработки не применяется: локальный VPN уже включён.
- Хранение отдельных объяснений и классификаций ошибок не является требованием MVP.

## Открытые вопросы

- Модель и кандидаты, точный промпт, поддержка полного отключения reasoning, измеримые пороги качества/скорости и бюджет тестирования.
- Включение английского и французского в MVP.
- Реализация и проверка утверждённых UI-прототипов, лимит текста, стриминг, повторы и политика кеша.
- Настройки TypeScript, версии пакетов и инструменты тестирования.
- Слой доступа к SQLite, окончательная схема и API-контракты.
- Точная конфигурация окружений, инфраструктурная блокировка при падении VPN, резервное копирование.
- Авторизация, TLS и способ входа с телефона вне дома — намеренно отложены.

Предложения по данным и UX в тематических документах служат основой обсуждения. Не превращать их в скрытые обязательные требования.

## Как обновлять

При новом существенном решении записать результат и причину, обновить основной тематический документ, а устаревшее решение явно отметить как заменённое. Не хранить несколько противоречащих друг другу «актуальных» вариантов.
