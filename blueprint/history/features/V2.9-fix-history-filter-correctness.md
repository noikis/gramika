# Feature: Fix history filter correctness

**From build-plan:** feature V2.9
**Build attempt:** 1
**Branch:** feature/fix-history-filter-correctness
**Status:** verified

## Goal

Offer only supported models in the history filter and show only requests matching
the selected model and result inside expanded entries, preserving saved history.

## In scope

- Populate the picker from the shared MODELS registry: All models, Gemma and
  Gemini. Unsupported historical models remain readable under All models.
- Apply model and result criteria together to each displayed request. Corrected
  means succeeded with output different from the exact original; No changes means
  succeeded with identical output. Failed and Pending use recorded status.
- Retain original text, matching request details, costs, Copy, local diff and
  applicable explanations. Whole-entry deletion retains its current meaning.
- Verify combined search, model, result, date, sort, page, reset and empty states.

## Out of scope

- Server behavior or public API changes, migrations, deleting historical models,
  new dependencies, filter restyling, PWA, caching and V2.10 output recovery.
- Commits, merge, push, deployment, paid model calls and benchmark execution.

## Data / contracts

No persisted data or response shape changes. Search remains case-insensitive
phrase matching across the original or any successful result at entry level;
it need not match the particular request selected by model/result. The backend
already applies model and result to the same attempt. Date filters use correction
creation time, inclusive start and exclusive next-day end. Stable timestamp/ID
sorting, ten-entry pages and server page clamping remain intact. Reset clears
search/model/result/dates and returns to page one while retaining sort.

The detail endpoint intentionally returns every request. Restrict display in the
frontend without discarding stored attempts. All models continues to include
retired historical models. Preserve safe React text rendering, accessible form
labels, status/error announcements, keyboard controls and phone usability.
